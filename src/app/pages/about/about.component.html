Microsserviços & Back-end

Arquitetura dividida em 6 serviços especialistas, garantindo escalabilidade e isolamento de falhas (Database-per-Service).

Java 17 Spring Boot 3 Quarkus Spring Cloud Gateway Eureka Server

DevOps & Orquestração

Ambiente 100% containerizado com Docker Multi-stage builds e preparado para orquestração em Kubernetes.

Docker Kubernetes GitHub Actions (CI/CD) Testcontainers Nginx

Mensageria & Dados

Comunicação assíncrona orientada a eventos (Event-Driven) para auditoria e alta vazão de dados.

PostgreSQL Redis (Cache) Apache Kafka RabbitMQ Spring Batch

Resiliência & Observabilidade

Monitoramento de saúde do cluster, rastreabilidade ponta a ponta e tolerância a falhas na comunicação.
